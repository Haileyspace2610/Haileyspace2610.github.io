### 💘 42. フラれる (ふられる)

**中文意思**：被甩／告白被拒<br>
**使用場合**：告白失敗或被戀人提出分手時（主動甩人則是「フル」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 43. 脈あり (みゃくあり)

**中文意思**：有戲／有機會<br>
**使用場合**：觀察喜歡的人的反應後，判斷對方對自己也有好感（沒機會則是「脈なし」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 44. キュン死 (きゅんじに)

**中文意思**：心動到快死掉／萌死<br>
**使用場合**：看到喜歡的人或偶像做出超帥、超可愛的舉動，心臟受不了的誇張表達。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 45. 壁ドン (かべどん)

**中文意思**：壁咚<br>
**使用場合**：男性將女性逼到牆邊，單手拍牆發出「咚」一聲的經典少女漫畫動作。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 46. 合コン (ごうこん)

**中文意思**：聯誼<br>
**使用場合**：「合同コンパ」的簡稱，男女各湊幾個人一起吃飯喝酒認識新朋友的聚會。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 47. 女子会 (じょしかい)

**中文意思**：姊妹淘聚會<br>
**使用場合**：只有女性參加的聚餐、下午茶或旅行。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 48. 飲みニケーション (のみにけーしょん)

**中文意思**：喝酒社交<br>
**使用場合**：「飲み会（酒會）」＋「コミュニケーション（溝通）」，指透過下班喝酒拉近關係的文化。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 49. ドタキャン (どたきゃん)

**中文意思**：臨時放鴿子<br>
**使用場合**：「土壇場キャンセル」的簡稱，在約定時間快到前才突然取消約會。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 50. 既読スルー (きどくするー)

**中文意思**：已讀不回<br>
**使用場合**：LINE 訊息顯示「已讀」卻遲遲不回覆（未讀不回則是「未読スルー」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 51. 塩対応 (しおたいおう)

**中文意思**：冷淡回應／敷衍<br>
**使用場合**：偶像在握手會上對粉絲態度冷漠，或朋友回訊息非常簡短冷淡（熱情回應為「神対応」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 52. 気まずい (きまずい)

**中文意思**：尷尬／氣氛僵硬<br>
**使用場合**：吵架後見面、冷場或說錯話時，現場氣氛讓人坐立難安。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 53. ノリがいい (のりがいい)

**中文意思**：很配合／玩得開／好相處<br>
**使用場合**：形容別人開玩笑或提議去玩時，能立刻接梗並熱情參與的人（難相處則是「ノリが悪い」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 54. ツッコミ (つっこみ)

**中文意思**：吐槽<br>
**使用場合**：源自漫才（相聲），指針對別人說的蠢話或荒謬行為立刻糾正吐槽（裝傻則是「ボケ」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 55. 盛る (もる)

**中文意思**：誇大／修圖修很大<br>
**使用場合**：拍照開美肌濾鏡讓自己變好看，或講故事時加油添醋誇大其詞。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 56. 映える (ばえる)

**中文意思**：很上相／適合拍照打卡<br>
**使用場合**：「インスタ映え（IG網美照）」的簡稱，指食物、景點拍起來非常漂亮吸睛。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 57. ぶっちゃけ (ぶっちゃけ)

**中文意思**：老實說／坦白講<br>
**使用場合**：準備說出真心話、秘密或不太好聽的實話前的開場白。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 58. ちなみに (ちなみに)

**中文意思**：順便一提<br>
**使用場合**：在對話中補充相關的額外資訊時使用。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 59. ワンチャン (わんちゃん)

**中文意思**：說不定有機會／萬一<br>
**使用場合**：「ワンチャンス（One chance）」的簡稱，指「雖然機率不高，但或許有機會成功」。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💘 60. どうでもいい (どうでもいい)

**中文意思**：隨便啦／無所謂<br>
**使用場合**：對某件事完全不在乎、怎麼樣都行（有時帶有不耐煩的語氣）。

</div>
