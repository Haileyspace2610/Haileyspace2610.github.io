# 1. 心情大起大落・喜怒哀樂發洩區 😱

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 1. ヤバい (やばい / yabai)

**中文意思**：糟了／超讚／太厲害了<br>
**使用場合**：萬用感嘆詞，原本指「危險、不妙」，現在常表示「好吃到爆、超好玩、太扯了」。

### 🔥 2. マジで (まじで / majide)

**中文意思**：真的假的？／認真的<br>
**使用場合**：聽到驚訝消息時確認真偽，或強調自己沒有在開玩笑（比「本当」更口語）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 3. 超〜 (ちょう〜 / chou~)

**中文意思**：超級〜／非常〜<br>
**使用場合**：接在形容詞或動詞前加強語氣，如「超美味しい（超好吃）」、「超楽しい（超好玩）」。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 4. めっちゃ (めっちゃ / meccha)

**中文意思**：非常／超級<br>
**使用場合**：關西腔演變而來的全國通用流行語，用法同「超」，如「めっちゃ可愛い（超可愛）」。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 5. エモい (えもい / emoi)

**中文意思**：很有感覺／令人懷舊感動<br>
**使用場合**：看到夕陽、老照片或聽老歌時，湧起難以言喻的感動、懷舊或浪漫情緒。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 6. 尊い (とうとい / toutoi)

**中文意思**：太神聖了／好感動／太美好了<br>
**使用場合**：看到偶像、喜歡的角色或感人互動時，表達超越「喜歡」的崇敬與感動。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 7. 最高 (さいこう / saikou)

**中文意思**：最棒了／太爽了<br>
**使用場合**：吃到美食、看到精彩表演或心情極好時的讚嘆。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 8. 最悪 (さいあく / saiaku)

**中文意思**：糟透了／真倒楣<br>
**使用場合**：遇到下雨沒帶傘、錯過末班車等倒楣事時的抱怨。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 9. ウケる (うける / ukeru)

**中文意思**：超好笑／笑死<br>
**使用場合**：聽到好笑的笑話或看到滑稽的畫面時（年輕人常用來代替「面白い」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 10. 草 (くさ / kusa)

**中文意思**：笑死（哈哈哈）<br>
**使用場合**：網路用語，因日文笑聲「wwww」長得像草地，口語也會直接說「草生える（長草了＝笑死）」。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 11. 萎える (なえる / naeru)

**中文意思**：掃興／沒勁／洩氣<br>
**使用場合**：原本很期待某件事，卻因為突發狀況而瞬間失去興致或幹勁。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 12. 凹む (へこむ / hekomu)

**中文意思**：沮喪／受打擊／心情低落<br>
**使用場合**：被罵、考試考差或工作出包後，心情像被撞凹一樣低落。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 13. キレる (きれる / kireru)

**中文意思**：暴怒／發飆／理智線斷裂<br>
**使用場合**：忍無可忍突然大發脾氣（如「マジギレ＝真發火」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 14. ビビる (びびる / bibiru)

**中文意思**：嚇一跳／膽怯／畏縮<br>
**使用場合**：被突如其來的聲音嚇到，或在強大對手面前感到害怕退縮。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 15. ドキドキ (どきどき / dokidoki)

**中文意思**：心跳加速／緊張又期待<br>
**使用場合**：告白前、拆禮物前或遇到喜歡的人時，形容心臟噗通噗通跳。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 16. ワクワク (わくわく / wakuwaku)

**中文意思**：興奮期待<br>
**使用場合**：出國旅行前夕、期待周末活動時，心情雀躍不已。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 17. イライラ (いらいら / iraira)

**中文意思**：煩躁／焦躁不安<br>
**使用場合**：塞車、等人遲到或事情不順遂時，心裡感到很煩躁。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 18. モヤモヤ (もやもや / moyamoya)

**中文意思**：悶悶不樂／心裡卡卡的<br>
**使用場合**：事情沒解決或對某人的話耿耿於懷，心裡像起霧一樣不痛快。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 19. ほっとする (ほっとする / hottosuru)

**中文意思**：鬆一口氣／放心<br>
**使用場合**：考試結束、確認家人平安後，緊張感解除的瞬間。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🔥 20. むかつく (むかつく / mukatsuku)

**中文意思**：火大／讓人不爽<br>
**使用場合**：被別人挑釁、遇到沒禮貌的人時，心裡湧起厭惡與憤怒（粗俗口語）。

</div>
