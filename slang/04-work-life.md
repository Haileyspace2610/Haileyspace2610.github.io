### 💼 62. サボる (さぼる)

**中文意思**：翹課／偷懶／摸魚<br>
**使用場合**：源自法文 sabotage，指故意不去上課、上班，或在工作時偷懶滑手機。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 63. 徹夜 (てつや)

**中文意思**：熬夜／通宵<br>
**使用場合**：為了趕報告、準備考試或打遊戲而整晚沒睡（年輕人也常說「オールする」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 64. 寝坊する (ねぼうする)

**中文意思**：睡過頭<br>
**使用場合**：鬧鐘沒響或賴床導致起床遲到。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 65. ギリギリ (ぎりぎり)

**中文意思**：勉強趕上／極限邊緣<br>
**使用場合**：壓線趕上電車、考試勉強及格，或時間非常緊迫的狀態。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 66. バタバタ (ばたばた)

**中文意思**：忙得不可開交／手忙腳亂<br>
**使用場合**：工作太多、行程太滿，忙到團團轉的狀態。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 67. テンパる (てんぱる)

**中文意思**：慌張／腦袋當機<br>
**使用場合**：源自麻將「聴牌」，指遇到突發狀況或壓力太大，緊張到腦袋一片空白、手足無措。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 68. ググる (ぐぐる)

**中文意思**：用 Google 搜尋<br>
**使用場合**：不懂某件事時，叫對方「自己上網查（ググって）」。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 69. ポチる (ぽちる)

**中文意思**：網購下單（按滑鼠）<br>
**使用場合**：形容在購物網站上按下「購買鍵」的動作，常用於衝動購物後。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 70. 衝動買い (しょうどうがい)

**中文意思**：衝動購物<br>
**使用場合**：原本沒打算買，看到特價或可愛商品忍不住立刻買下來。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 71. 金欠 (きんけつ)

**中文意思**：缺錢／手頭緊<br>
**使用場合**：月底快沒錢吃飯、預算見底時的常用語。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 72. 奢る (おごる)

**中文意思**：請客<br>
**使用場合**：吃飯或買飲料時表示「這頓我請客（俺が奢るよ）」。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 73. 割り勘 (わりかん)

**中文意思**：AA制／平分帳單<br>
**使用場合**：聚餐結帳時大家平均分攤費用。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 74. 飯テロ (めしてろ)

**中文意思**：宵夜文／美食轟炸<br>
**使用場合**：半夜在社群媒體發誘人的美食照，折磨正在減肥或肚子餓的人。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 75. 宅飲み (たくのみ)

**中文意思**：在家喝酒聚會<br>
**使用場合**：不去居酒屋，而是買酒和零食到朋友家裡聚會喝酒。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 76. 二日酔い (ふつかよい)

**中文意思**：宿醉<br>
**使用場合**：昨晚喝太多酒，隔天起床頭痛、想吐的狀態。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 77. 爆睡 (ばくすい)

**中文意思**：熟睡／睡死<br>
**使用場合**：累到一躺上床就立刻睡著，怎麼叫都叫不醒。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 78. 引きこもり (ひきこもり)

**中文意思**：家裡蹲／足不出戶<br>
**使用場合**：長期關在家裡不出門的人，日常也用來開玩笑說假日整天在家耍廢。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 79. チルする (ちるする)

**中文意思**：放鬆／耍廢享受悠閒<br>
**使用場合**：源自英文 Chill，指聽音樂、喝咖啡、什麼都不做地悠閒放鬆。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #ff6b6b; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💼 80. 社畜 (しゃちく)

**中文意思**：社畜<br>
**使用場合**：自嘲像公司的牲畜一樣拼命加班、任勞任怨的上班族。

</div>
