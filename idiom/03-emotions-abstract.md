# 3. 內心戲太多・情感與抽象概念 💭

### 💭 56. 気が利く (きがきく)

**中文意思**：機靈／貼心／會看臉色<br>
**使用場合**：稱讚某人觀察入微，能主動察覺別人需求並照顧周到時。

### 💭 57. 気が置けない (きがおけない)

**中文意思**：無拘無束／相處自在<br>
**使用場合**：形容與好朋友之間完全不需要客套或拘謹（注意：非負面意思）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 58. 気が重い (きがおもい)

**中文意思**：心情沉重／提不起勁<br>
**使用場合**：想到明天要開會、考試或處理麻煩事而感到憂鬱時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 59. 気が散る (きがちる)

**中文意思**：分心／注意力不集中<br>
**使用場合**：周圍太吵或心裡想著別的事，無法專注在眼前的事時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 60. 気を取り直す (きをとりなおす)

**中文意思**：重新振作／打起精神<br>
**使用場合**：遭遇失敗或沮喪後，調整心情重新開始時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 61. 気を使う (きをつかう)

**中文意思**：費心／顧慮周到<br>
**使用場合**：在社交場合或對待客人時小心翼翼、顧慮對方感受。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 62. 虫がいい (むしがいい)

**中文意思**：太自私／想得美<br>
**使用場合**：批評某人只考慮自己利益、不顧別人感受或提出無理要求時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 63. 虫の居所が悪い (むしのいどころがわるい)

**中文意思**：心情不好／莫名發脾氣<br>
**使用場合**：形容某人今天不知為何特別暴躁、容易動怒時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 64. 虫が知らせる (むしがしらせる)

**中文意思**：第六感預感（多指壞事）<br>
**使用場合**：沒有根據卻突然有種不祥的預感（俗稱「虫の知らせ」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 65. 根に持つ (ねにもつ)

**中文意思**：耿耿於懷／記仇<br>
**使用場合**：過去被得罪或受委屈的事一直記在心裡、無法釋懷時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 66. 根を上げる (ねをあげる)

**中文意思**：吃不消／喊苦認輸<br>
**使用場合**：工作太累或訓練太嚴格，受不了而抱怨放棄時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 67. 羽を伸ばす (はねをのばす)

**中文意思**：放鬆心情／盡情玩樂<br>
**使用場合**：趁著休假或沒有長輩管束時，自由自在地放鬆享受。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 68. 鼻を明かす (はなをあかす)

**中文意思**：讓對方大吃一驚／挫其銳氣<br>
**使用場合**：做出超越對手預期的表現，讓對方刮目相看或不甘心時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 69. 水を差す (みずをさす)

**中文意思**：潑冷水／挑撥離間<br>
**使用場合**：在大家興高采烈時說掃興的話，或破壞原本和諧的氣氛。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 70. 水に流す (みずにながす)

**中文意思**：一筆勾銷／既往不咎<br>
**使用場合**：過去的恩怨、誤會或爭吵全部忘掉，重新和好時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 71. 油を売る (あぶらをうる)

**中文意思**：偷懶聊天／摸魚打混<br>
**使用場合**：上班或辦事途中停下來跟人閒聊、浪費時間時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 72. 火を見るより明らか (ひをみるよりあきらか)

**中文意思**：顯而易見／一目了然<br>
**使用場合**：事情的結果非常明確，就像看到火光一樣清楚無疑。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 73. 藪から棒 (やぶからぼう)

**中文意思**：突如其來／毫無預警<br>
**使用場合**：沒有任何前兆就突然提出某個要求或話題時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 74. 寝耳に水 (ねみみにみず)

**中文意思**：晴天霹靂／大吃一驚<br>
**使用場合**：在完全沒心理準備的情況下，突然聽到震驚的消息時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 75. 猿も木から落ちる (さるもきからおちる)

**中文意思**：智者千慮必有一失<br>
**使用場合**：再厲害的高手也有失手犯錯的時候（用來安慰失誤的人）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 76. 井の中の蛙 (いのなかのかわず)

**中文意思**：井底之蛙<br>
**使用場合**：形容見識狹隘、只知道自己小圈子裡的事情卻自以為是的人。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 77. 鬼に金棒 (おににかなぼう)

**中文意思**：如虎添翼<br>
**使用場合**：原本就很強的人又獲得強大武器或助力，變得更加無敵時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 78. 豚に真珠 (ぶたにしんじゅ)

**中文意思**：對牛彈琴／暴殄天物<br>
**使用場合**：把珍貴的東西交給不懂其價值的人，完全發揮不了作用。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 79. 猫に小判 (ねこにこばん)

**中文意思**：對牛彈琴（同上）<br>
**使用場合**：給完全不懂價值的人再貴重的物品也毫無意義。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 💭 80. 棚から牡丹餅 (たなからぼたもち)

**中文意思**：天上掉下來的餡餅／意外之財<br>
**使用場合**：沒有付出努力卻意外獲得好處或幸運降臨時。

</div>
