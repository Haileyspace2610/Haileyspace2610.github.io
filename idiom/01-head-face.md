# 1. 由頭到面・五官相關慣用語 👁️

### 🧠 1. 頭が固い (あたまがかたい)

**中文意思**：腦筋死板／不知變通<br>
**使用場合**：形容人固執己見、無法接受新觀念或彈性調整時。

### 🧠 2. 頭が下がる (あたまがさがる)

**中文意思**：令人敬佩／五體投地<br>
**使用場合**：看到別人無私奉獻、努力不懈，由衷感到佩服時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 3. 頭を抱える (あたまをかかえる)

**中文意思**：傷腦筋／束手無策<br>
**使用場合**：遇到棘手難題、不知該如何解決而煩惱時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 4. 頭に来る (あたまにくる)

**中文意思**：生氣／火冒三丈<br>
**使用場合**：被激怒、感到非常氣憤時（口語常用）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 5. 顔が広い (かおがひろい)

**中文意思**：交遊廣闊／人脈很廣<br>
**使用場合**：形容某人認識各行各業的人、到哪都有熟人時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 6. 顔を潰す (かおをつぶす)

**中文意思**：丟臉／讓人下不了台<br>
**使用場合**：公開指責別人或破壞約定，損害對方的面子與名譽時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 7. 顔から火が出る (かおからひがでる)

**中文意思**：羞愧得無地自容<br>
**使用場合**：犯了大錯或出糗，害羞到整張臉發燙通紅時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 8. 目が高い (めがたかい)

**中文意思**：眼光好／有鑑賞力<br>
**使用場合**：稱讚別人挑選商品、藝術品或看人的眼光很準確時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 9. 目が回る (めがまわる)

**中文意思**：忙得團團轉／頭暈眼花<br>
**使用場合**：工作或雜事太多，忙到喘不過氣時（如「目が回るほど忙しい」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 10. 目がない (めがない)

**中文意思**：非常喜歡／毫無抵抗力<br>
**使用場合**：形容對甜食、酒或特定事物極度熱愛、看到就忍不住時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 11. 目を丸くする (めをまるくする)

**中文意思**：瞪大眼睛／大吃一驚<br>
**使用場合**：看到令人驚訝或意外的景象時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 12. 目を皿にする (めをさらにする)

**中文意思**：睜大眼睛仔細尋找<br>
**使用場合**：專注地尋找遺失物，或緊盯著細節看時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 13. 目と鼻の先 (めとはなのさき)

**中文意思**：咫尺之間／非常近<br>
**使用場合**：形容兩地距離極近，走幾步路就到了。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 14. 耳が痛い (みみがいたい)

**中文意思**：聽了刺耳／說中痛處<br>
**使用場合**：別人指出的缺點正好是自己的弱點，聽起來很難受時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 15. 耳にタコができる (みみにたこができる)

**中文意思**：聽到耳朵長繭<br>
**使用場合**：同一件事被反覆唠叨或聽了無數次感到厭煩時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 16. 耳を傾ける (みみをかたむける)

**中文意思**：側耳傾聽／虛心聽取<br>
**使用場合**：專心聽取別人的意見、建議或訴苦時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 17. 鼻が高い (はながたかい)

**中文意思**：引以為傲／很得意<br>
**使用場合**：因為自己或家人、朋友的成就而感到光榮自豪時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 18. 鼻につく (はなにつく)

**中文意思**：令人反感／生厭<br>
**使用場合**：形容某人愛炫耀、態度傲慢或味道太濃讓人討厭時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 19. 鼻で笑う (はなでわらう)

**中文意思**：嗤之以鼻／冷笑<br>
**使用場合**：輕視、看不起對方的言行而從鼻子哼出笑聲時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 20. 口が堅い (くちがかたい)

**中文意思**：口風緊／守口如瓶<br>
**使用場合**：稱讚某人能保守秘密、不會隨便洩漏消息時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 21. 口が軽い (くちがかるい)

**中文意思**：嘴巴不牢／愛大嘴巴<br>
**使用場合**：批評某人藏不住秘密、愛四處張揚八卦時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 22. 口が滑る (くちがすべる)

**中文意思**：說溜嘴<br>
**使用場合**：不小心把不該說的秘密或真心話脫口而出時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 23. 口を出す (くちをだす)

**中文意思**：插嘴／多管閒事<br>
**使用場合**：在別人討論或做事時隨意發表意見、干涉別人時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 24. 歯が立たない (はがたたない)

**中文意思**：束手無策／完全不是對手<br>
**使用場合**：面對實力差距懸殊的對手或極難的考題，完全無法應付時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #9C27B0; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🧠 25. 舌を巻く (したをまく)

**中文意思**：驚嘆不已／佩服得五體投地<br>
**使用場合**：看到別人展現出高超技藝或驚人表現時。

</div>
