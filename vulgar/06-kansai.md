# 6. 關西腔狠話・惡霸級粗口 🐆

> 🚨 **嚴重警告**：本區為關西地區特有的強烈威脅與辱罵用語，充滿濃厚的黑道與不良少年色彩。僅供日文學習與動漫影劇賞析，**請絕對不要在現實生活中使用，極易引發肢體衝突**。

**中文意思**：你白痴啊<br>
**使用場合**：關西最基本吐槽或罵人語（輕微時是朋友開玩笑，語氣重時則是真罵人）。

### 🐆 137. ボケ (ぼけ)

**中文意思**：呆子／蠢貨<br>
**使用場合**：在關西比「アホ」更具攻擊性，真正生氣罵人時才會用。

</div>

### 🐆 138. カス (かす)

**中文意思**：廢物／人渣<br>
**使用場合**：關西吵架高頻詞彙，常連用成「アホ・ボケ・カス」三連罵。

</div>

### 🐆 139. どアホ (どあほ)

**中文意思**：大白痴／超級蠢蛋<br>
**使用場合**：加上強調前綴「ど」，代表極度憤怒的謾罵。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 140. どつき回すぞ (どつきまわすぞ)

**中文意思**：把你海扁一頓喔<br>
**使用場合**：關西腔威脅要動手揍人的狠話（「どつく」意為毆打）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 141. しばくぞ (しばくぞ)

**中文意思**：扁你喔／抽死你<br>
**使用場合**：關西腔經典威脅用語（「しばく」意為打人，年輕人有時也開玩笑說「お茶しばく＝去喝茶」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 142. ぼこぼこにするぞ (ぼこぼこにするぞ)

**中文意思**：把你打得鼻青臉腫喔<br>
**使用場合**：威脅要將對方打到變形的粗暴狠話。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 143. 調子こくな (ちょうしこくな)

**中文意思**：別太囂張了<br>
**使用場合**：關西腔的「調子に乗るな」，警告對方別得意忘形。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 144. 舐めとんのか (なめとんのか)

**中文意思**：你是看不起我嗎／把人當傻瓜嗎<br>
**使用場合**：關西腔挑釁用語，對應標準語的「なめているのか」。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 145. 誰に口きいとんねん (だれにくちきいとんねん)

**中文意思**：你是在跟誰講話啊？！<br>
**使用場合**：對晚輩或對手不禮貌的態度感到憤怒時的威嚇。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 146. 何さらしとんねん (なにさらしとんねん)

**中文意思**：你在搞什麼鬼啊？！<br>
**使用場合**：「さらす」在關西腔是「做（卑劣的事）」的粗俗說法，用於怒斥對方搞砸事情。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 147. ええ加減にせえよ (ええかげんにせえよ)

**中文意思**：給我適可而止喔<br>
**使用場合**：關西腔的「いい加減にしろ」，忍無可忍時的警告。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 148. 黙っとれ (だまっとれ)

**中文意思**：給我閉嘴待著<br>
**使用場合**：粗魯地命令對方安靜不要插嘴。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #b00020; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🐆 149. 引っ込んどれ (ひっこんどれ)

**中文意思**：給我滾一邊去<br>
**使用場合**：叫礙事的人退下別擋路。

</div>

### 🐆 150. 邪魔くさい (じゃまくさい)

**中文意思**：真麻煩／真礙事<br>
**使用場合**：嫌事情繁瑣或嫌別人擋路時的抱怨。

</div>

**中文意思**：笨手笨腳／反應遲鈍<br>

### 🐆 152. しょうもない (しょうもない)

**中文意思**：無聊透頂／沒價值<br>

</div>

### 🐆 153. くだらん (くだらん)

</div>

### 🐆 154. 知らんがな (しらんがな)

### 🐆 155. 関係ないやろ (かんけいないやろ)

### 🐆 156. ほっといてくれ (ほっといてくれ)

**中文意思**：小氣／卑鄙／愛佔小便宜<br>

### 🐆 160. いけず (いけず)

**中文意思**：壞心眼／愛刁難人<br>

### 🐆 162. 鬱陶しい (うっとうしい)

**中文意思**：煩死了／真討厭<br>

### 🐆 163. 阿呆たれ (あほたれ)

**中文意思**：蠢貨／大笨蛋<br>

### 🐆 164. どたまかち割るぞ (どたまかちわるぞ)

**中文意思**：敲破你的腦袋喔<br>

### 🐆 165. 往ね (いね)

**中文意思**：滾／去死<br>
