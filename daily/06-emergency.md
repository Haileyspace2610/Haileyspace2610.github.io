### 🚨 91. 助けてください (たすけてください)

**中文意思**：請救救我／幫幫我<br>
**使用場合**：遇到危險、突發狀況或急需他人援手時。

### 🚨 92. 警察を呼んでください (けいさつをよんでください)

**中文意思**：請幫我叫警察<br>
**使用場合**：遇到犯罪、交通事故或遺失重要財物時。

</div>

### 🚨 93. 救急車を呼んでください (きゅうきゅうしゃをよんでください)

**中文意思**：請幫我叫救護車<br>
**使用場合**：自己或身邊的人突發重病、受重傷時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🚨 94. 気分が悪いです (きぶんがわるいです)

**中文意思**：我身體不舒服／想吐<br>
**使用場合**：感到頭暈、噁心或身體不適時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🚨 95. 病院に行きたいです (びょういんにいきたいです)

**中文意思**：我想去醫院<br>
**使用場合**：生病或受傷需要就醫，向飯店人員或路人求助時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🚨 96. パスポートをなくしました (ぱすぽーとをなくしました)

**中文意思**：我把護照弄丟了<br>
**使用場合**：在海外遺失護照，向警察局報案時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🚨 97. 写真を撮ってもいいですか (しゃしんをとってもいいですか)

**中文意思**：可以拍照嗎？<br>
**使用場合**：在神社、美術館、商店或對著人物拍照前徵求同意。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🚨 98. 写真を撮ってもらえますか (しゃしんをとってもらえますか)

**中文意思**：可以幫我拍照嗎？<br>
**使用場合**：在觀光景點請路人幫忙拍合照或獨照時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🚨 99. トイレはどこですか (といれはどこですか)

**中文意思**：洗手間在哪裡？<br>
**使用場合**：在商場、車站或餐廳詢問廁所位置時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🚨 100. 楽しかったです (たのしかったです)

**中文意思**：很開心／很好玩<br>
**使用場合**：聚會、旅行或活動結束道別時，表達今天過得很愉快。

</div>
