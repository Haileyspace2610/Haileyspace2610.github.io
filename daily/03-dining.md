# 3. 搵食大過天・餐廳點餐必備 🍜

### 🍽️ 41. 頂きます (いただきます)

**中文意思**：我開動了<br>
**使用場合**：用餐前雙手合十，感謝食物與準備餐點的人。

### 🍽️ 42. ご馳走様でした (ごちそうさまでした)

**中文意思**：謝謝款待／我吃飽了<br>
**使用場合**：用餐完畢後，對主人、廚師或餐廳店員表達感謝。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 43. お腹が空きました (おなかがすきました)

**中文意思**：肚子餓了<br>
**使用場合**：表達自己肚子餓、想吃東西時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 44. お腹がいっぱいです (おなかがいっぱいです)

**中文意思**：吃飽了<br>
**使用場合**：吃得很飽、吃不下更多食物時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 45. 喉が渇きました (のどがかわきました)

**中文意思**：口渴了<br>
**使用場合**：想喝水或飲料時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 46. 美味しいです (おいしいです)

**中文意思**：很好吃<br>
**使用場合**：稱讚食物美味時（男性或熟人之間常說「うまい」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 47. 乾杯 (かんぱい)

**中文意思**：乾杯<br>
**使用場合**：聚餐喝酒或喝飲料舉杯慶祝時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 48. 予約しています (よやくしています)

**中文意思**：我有預約<br>
**使用場合**：抵達餐廳或飯店櫃檯報到時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 49. 二人です (ふたりです)

**中文意思**：兩位<br>
**使用場合**：進入餐廳時告知店員用餐人數（一人：ひとり、三人：さんにん）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 50. 禁煙席をお願いします (きんえんせきをおねがいします)

**中文意思**：請給我禁菸區座位<br>
**使用場合**：在仍有分吸菸區與禁菸區的餐廳入座時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 51. メニューをください (めにゅーをください)

**中文意思**：請給我菜單<br>
**使用場合**：入座後向店員索取菜單時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 52. お水をお願いします (おみずをおねがいします)

**中文意思**：請給我水<br>
**使用場合**：在餐廳請店員倒水或續水時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 53. 注文をお願いします (ちゅうもんをおねがいします)

**中文意思**：我要點餐<br>
**使用場合**：決定好餐點，呼叫店員過來點餐時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 54. これをお願いします (これをおねがいします)

**中文意思**：我要這個<br>
**使用場合**：手指著菜單上的圖片或名稱點餐時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 55. おすすめは何ですか (おすすめはなんですか)

**中文意思**：推薦什麼呢？<br>
**使用場合**：不知道點什麼，請店員推薦招牌菜時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 56. 辛くしないでください (からくしないでください)

**中文意思**：請不要做辣的<br>
**使用場合**：不能吃辣，點餐時請廚房調整口味。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 57. アレルギーがあります (あれるぎーがあります)

**中文意思**：我有過敏<br>
**使用場合**：告知店員自己對特定食材過敏時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 58. お会計をお願いします (おかいけいをおねがいします)

**中文意思**：麻煩結帳<br>
**使用場合**：用餐完畢準備付款離開餐廳時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 59. 別々でお願いします (べつべつでおねがいします)

**中文意思**：請分開結帳<br>
**使用場合**：與朋友聚餐需要各自付各自的餐費時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🍽️ 60. 持ち帰りでお願いします (もちかえりでおねがいします)

**中文意思**：我要外帶<br>
**使用場合**：在咖啡廳或快餐店表示不內用、要帶走（內用為「店内で」）。

</div>
