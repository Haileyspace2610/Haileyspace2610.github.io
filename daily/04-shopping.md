### 🛍️ 62. 見ているだけです (みているだけです)

**中文意思**：我只是看看而已<br>
**使用場合**：店員上前推銷詢問時，禮貌表示自己先隨意逛逛。

</div>

### 🛍️ 63. これは幾らですか (これはいくらですか)

**中文意思**：這個多少錢？<br>
**使用場合**：詢問商品價格時。

</div>

### 🛍️ 64. 試着してもいいですか (しちゃくしてもいいですか)

**中文意思**：可以試穿嗎？<br>
**使用場合**：在服飾店想試穿衣服時。

</div>

### 🛍️ 65. 試着室はどこですか (しちゃくしつはどこですか)

**中文意思**：試衣間在哪裡？<br>
**使用場合**：尋找更衣室位置時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 66. もっと大きいサイズはありますか (もっとおおきいさいずはありますか)

**中文意思**：有更大一點的尺寸嗎？<br>
**使用場合**：衣服或鞋子太小，詢問是否有大一號的尺寸時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 67. 他の色はありますか (ほかのいろはありますか)

**中文意思**：有其他顏色嗎？<br>
**使用場合**：詢問同款商品是否有別的顏色可選。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 68. 新しいのをください (あたらしいのをください)

**中文意思**：請給我新的<br>
**使用場合**：不想買展示品，請店員拿庫存新品時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 69. 免税できますか (めんぜいできますか)

**中文意思**：可以退稅嗎？<br>
**使用場合**：在藥妝店、百貨公司購物達到退稅門檻時詢問。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 70. 袋はいりません (ふくろはいりません)

**中文意思**：不需要袋子<br>
**使用場合**：結帳時自備購物袋，不需加購塑膠袋或紙袋。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 71. 袋をお願いします (ふくろをおねがいします)

**中文意思**：請給我袋子<br>
**使用場合**：結帳時需要加購購物袋。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 72. カードで払えますか (かーどではらえますか)

**中文意思**：可以刷卡嗎？<br>
**使用場合**：確認店家是否接受信用卡付款。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 73. 現金で払います (げんきんではらいます)

**中文意思**：我用現金付款<br>
**使用場合**：告知店員要使用紙鈔或硬幣結帳。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 74. レシートをください (れしーとをください)

**中文意思**：請給我收據<br>
**使用場合**：結帳後索取購物明細或發票時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🛍️ 75. 返品できますか (へんぴんできますか)

**中文意思**：可以退貨嗎？<br>
**使用場合**：購買的商品有瑕疵或買錯，詢問能否退貨時。

</div>
