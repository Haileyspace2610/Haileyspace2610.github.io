### 🗺️ 76. 駅はどこですか (えきはどこですか)

**中文意思**：車站在哪裡？<br>
**使用場合**：在街上向路人詢問最近的電車站或地鐵站位置。

### 🗺️ 77. どうやって行きますか (どうやっていきますか)

**中文意思**：要怎麼去？<br>
**使用場合**：詢問前往某個目的地的交通方式或路線。

</div>

### 🗺️ 78. どのくらいかかりますか (どのくらいかかりますか)

**中文意思**：大概需要花多少時間？<br>
**使用場合**：詢問搭車或走路抵達目的地所需的時間。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 79. ここで降ります (ここでおります)

**中文意思**：我要在這裡下車<br>
**使用場合**：在擁擠的電車或公車上，請擋在門口的乘客借過時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 80. この電車は渋谷に行きますか (このでんしゃはしぶやにいきますか)

**中文意思**：這班電車有到澀谷嗎？<br>
**使用場合**：在月台確認列車行駛方向與停靠站時（地名可替換）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 81. 乗り換えはどこですか (のりかえはどこですか)

**中文意思**：在哪裡轉車？<br>
**使用場合**：詢問轉乘其他路線的車站或月台位置。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 82. 切符をなくしました (きっぷをなくしました)

**中文意思**：我把車票弄丟了<br>
**使用場合**：在改札口向站務人員求助遺失車票時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 83. 道に迷いました (みちにまよいました)

**中文意思**：我迷路了<br>
**使用場合**：找不到目的地，向路人或警察求助時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 84. 地図を書いてください (ちずをかいてください)

**中文意思**：請幫我畫地圖<br>
**使用場合**：聽不懂口頭指路，請對方簡單畫出路線圖時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 85. まっすぐ行ってください (まっすぐいってください)

**中文意思**：請直走<br>
**使用場合**：指引方向或搭計程車時請司機直行。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 86. 右に曲がってください (みぎにまがってください)

**中文意思**：請向右轉<br>
**使用場合**：指引方向或搭計程車時請司機右轉（左轉為「左に」）。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 87. チェックインをお願いします (ちぇっくいんをおねがいします)

**中文意思**：我要辦理入住<br>
**使用場合**：抵達飯店櫃檯辦理入住手續時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 88. チェックアウトは何時ですか (ちぇっくあうとはなんじですか)

**中文意思**：退房時間是幾點？<br>
**使用場合**：確認飯店規定的退房時間。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 89. 荷物を預かってもらえますか (にもつをあずかってもらえますか)

**中文意思**：可以幫我寄放行李嗎？<br>
**使用場合**：入住前或退房後想先把行李寄放在飯店櫃檯時。

</div>

<div style="background-color: #f9f9f9; border-left: 5px solid #4CAF50; padding: 15px; margin-bottom: 25px; border-radius: 8px; box-shadow: 0 2px 5px rgba(0,0,0,0.05);">

### 🗺️ 90. Wi-Fiのパスワードは何ですか (わいふぁいのぱすわーどはなんですか)

**中文意思**：Wi-Fi密碼是什麼？<br>
**使用場合**：在飯店、咖啡廳或餐廳詢問無線網路密碼時。

</div>
